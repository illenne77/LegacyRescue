# LegacyRescue

구형 윈도우 프로그램을 **기능을 깨뜨리지 않고** .NET 8로 현대화하는 과정을 처음부터 끝까지 보여주는 데모 프로젝트입니다.

## 시나리오

소규모 공장에서 오래 써 온 "생산 실적 관리" 프로그램(.NET Framework 4.8 WinForms)이 있습니다. 원 개발자는 없고, Windows 11에서는 화면이 깨지며, 데이터가 많아지면 조회 중 프로그램이 멈춥니다.

이 프로젝트는 그 프로그램을 다음 순서로 현대화합니다.

1. **진단** — 구조, 위험 요소, 숨은 계산 특이점을 분석한 보고서
2. **동작 고정** — 기존 결과를 기준값으로 저장하는 특성화 테스트(골든 마스터)
3. **로직 분리** — 화면에 묻혀 있던 계산·데이터 로직을 테스트 가능한 계층으로 이전
4. **신규 UI** — .NET 8 WPF + MVVM, 비동기 처리, HiDPI 대응
5. **검증** — 옮긴 뒤에도 결과가 기준값과 100% 일치함을 테스트로 증명

> 레거시 샘플은 이 데모를 위해 새로 작성한 가상의 프로그램입니다. 현장에서 자주 보는 문제를 의도적으로 재현했습니다.

## 구조

- `legacy/` — 현대화 전 프로그램 (Before)
- `modern/` — 현대화 후 프로그램 (After)
- `data/` — 샘플 DB 스크립트와 기준 결과(골든 파일)
- `docs/` — 작업 계획, 진단 보고서, 전후 비교
